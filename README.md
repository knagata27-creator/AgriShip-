# AgriShip - 農産物出荷管理アプリ

農家向けのiOS出荷管理アプリです。

## 主な機能

- 注文の受付・管理（氏名・住所・商品・クール区分・代引き）
- 電話番号から顧客情報を自動補完
- ヤマトB2クラウド用CSV出力
- 出荷伝票PDF生成・印刷
- 農園名・商品リストを自由に設定

## 特長

- 完全オフライン動作（ネット不要）
- データはすべてiPhone内に保存
- シンプルな操作で素早く注文登録
